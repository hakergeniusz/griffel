# 03/02 — Formatting actions

All formatting commands are available from the toolbar (see `02-ui-layout.md`
§5) and, where noted, from keyboard shortcuts (`04-keyboard-shortcuts.md`).
Every command edits only the Markdown source text. All commands behave as one
undoable step.

General definitions used below:

- **Wrap command** (bold, italic, strikethrough, code): places delimiter
  characters around text.
- **Prefix command** (headings, lists, block quote): places a line prefix.
- **Placeholder text** is inserted when there is nothing to act on, and is
  pre-selected so typing replaces it. The app does not dictate the wording;
  suggested labels are noted per command.

## 1. Wrap commands

Behavior for bold (`**`), italic (`_`), strikethrough (`~~`):

- **No selection**: inserts `delimiter + placeholder + delimiter` and selects
  the placeholder ("bold text", "italic text", "strikethrough text"
  respectively).
- **With selection**: the selected text is wrapped in the delimiters.
- **Toggle**: if the selection, extended by one delimiter's width on each
  side, already begins and ends with that delimiter, the delimiters are
  removed instead (unwrapping). Extension only happens when the buffer has
  enough characters on both sides.
- Surrounding whitespace inside the selection is kept outside the delimiters
  (the wrapped content is trimmed).
- After the command the inner text is selected.
- Code command: on an empty line inserts a fenced code block (``` placeholder
  ``` with "code" placeholder on its own line inside); elsewhere wraps the
  selection (or the "code" placeholder) in single backticks.

## 2. Heading command

- Applying the heading command to a line that is not a heading inserts `# `
  (level 1).
- Applying it to a line that already has a `#`-style heading **cycles** the
  level: 1 → 2 → 3 → no heading → 1 … (i.e. repeated application raises the
  level up to 3, and the next application removes the heading). Manually
  typed levels 4–6 cycle back down to 1.
- With a selection, the selection's first line becomes the heading text.
- On an empty line, inserts the marker plus the placeholder "Header",
  selected.
- If the current line is in the middle of the document (previous line has
  content) a blank line is inserted before the heading; if the cursor is not
  at the start of a line, a blank line and the heading are inserted on a new
  line.
- Setext heading styles (`===`) are never generated by commands.

## 3. List commands (bullet, numbered, checklist)

For each of the three list kinds:

- **No selection, cursor on an empty line**: inserts the marker plus the
  placeholder "Item", selected.
- **Cursor at start of a non-list line**: prefixes the line with the marker
  (e.g. `- `, `1. `, `- [ ] `).
- **Cursor mid-line** (not at line start): inserts a blank line and then the
  marker on the following line.
- **Toggle**: if the current line already has that kind of marker, the marker
  is removed (toggling off). For checklists, if the line already has a
  checklist marker, the checkbox state flips (`[ ]` ↔ `[x]`) instead of being
  removed.
- **Continuation**: when the previous line is an item of the same kind, the
  new item inherits its indentation and bullet symbol; for numbered lists the
  number increments and the delimiter is copied (`.` vs `)`).
- **Spacing**: if the line two above is blank (i.e. this would start a new
  list), a blank line is inserted before the marker.
- **With selection**: the selected text becomes the item text (the marker is
  placed at the start of the current line); if the current line already has
  such a marker, the marker's text is selected for retyping.

## 4. Block quote command

- Cursor at line start: toggles `> ` on the line (removes it if present).
- Cursor mid-line: inserts a blank line and `> ` on the next line.
- Empty line: inserts `> ` plus placeholder "Quote", selected.
- A blank line is inserted first when the previous line has content.

## 5. Link command

- **No selection**: inserts `[link text](https://www.example.com)` with the
  URL part selected for typing.
- **Selection is a URL**: the text becomes the label and the URL is kept:
  `[label](selected-url)`; the label is selected.
- **Selection is not a URL**: the text becomes the label and a placeholder
  URL is used: `[selected-text](https://www.example.com)`; the URL is
  selected.

## 6. Image command

Opens an image file chooser (images MIME filter, modal). After a choice:

- Inserts `![caption](path)` at the cursor, with **caption** selected.
- If there is a selection, its text becomes the caption.
- The path is relative to the document's folder when the image lies within
  it, otherwise the absolute path; percent-encoded (`01-editing.md` §3).
- The document's folder is the starting folder of the chooser.
- Canceling the chooser just returns focus to the editor.

## 7. Table command

- The table toolbar button opens, inside the expanded toolbar, a size picker:
  a grid of cells (hover highlights the selected rows×columns region and a
  label shows "R x C"; up to 5×5). Activating a cell inserts a table of that
  size at the cursor.
- The inserted table is a fixed-width plain-text table: header row of blank
  cells, a separator row of dashes, then one row per remaining rows, with
  cell width chosen so the table fits the "characters per line" setting
  (cells capped at 20 characters wide).
- A "fix table" affordance (available when the cursor is inside such a table)
  re-aligns all columns to the widest cell in each column. Table recognition:
  lines containing `|` or `+` adjacent to the cursor's line.

## 8. Horizontal rule command

Inserts a blank line, `---`, and a blank line at the cursor, then scrolls the
inserted rule into view. (Shortcut: Ctrl+R, if registered — see
`04-keyboard-shortcuts.md`.)
